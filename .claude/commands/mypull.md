# Git Pull (내 브랜치만)

현재 브랜치의 최신 변경사항을 origin에서 가져온다. develop은 건드리지 않는다.

## 실행 절차

1. `git status`로 커밋 안 된 변경사항 확인
   - 커밋 안 된 변경사항이 있으면 사용자에게 먼저 커밋하거나 stash할지 물어보기
2. 현재 브랜치 이름 확인 (`git branch --show-current`)
3. `git pull origin <현재브랜치>`
4. 완료 후 결과 요약 출력 (새로 받은 커밋 수, 변경된 파일 등)

## 주의사항
- 충돌 발생 시 자동 해결하지 말고 사용자에게 보고
- `--force` 절대 사용 금지
