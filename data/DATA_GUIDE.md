## 수집할 데이터 6종류

### 1. Intent 분류 문장 — 1,400건

사용자가 채팅에 입력하는 문장을 **7개 의도 중 하나로 분류**하는 AI를 학습시키는 데이터입니다.
카테고리당 200건, 총 1,400건이 필요합니다.

**양식:**
```json
{"text": "사용자 입력 문장", "label": "의도"}
```

**카테고리별 예시:**

| 의도 (label) | 설명 | 예시 문장 |
|-------------|------|----------|
| `judgment` | 규정상 되는지/안되는지 판단 | "인턴에게 서버 접근 권한 줘도 돼?" |
| `doc_search` | 규정/문서 검색 질문 | "보안 규정 몇 조에 나와있어?" |
| `doc_generate` | 문서 생성 요청 | "이 내용으로 보고서 만들어줘" |
| `meeting_generate` | 회의록 정리 요청 | "오늘 회의 내용 정리해줘" |
| `schedule_add` | 일정 추가 요청 | "내일 3시에 미팅 잡아줘" |
| `schedule_view` | 일정 조회 요청 | "이번주 일정 보여줘" |
| `general` | 일상 대화/인사 | "고마워", "안녕" |

**수집 방법:**
ChatGPT/Claude에게 아래처럼 요청하면 대량 생성 가능합니다.
```
너는 한국 IT 기업의 사내 업무 도우미 챗봇이야.
"judgment" 의도에 해당하는 한국어 문장 200개를 만들어줘.
judgment는 "회사 규정상 이게 허용되는지 판단해달라"는 의미야.

조건:
- 반말/존댓말 섞기
- 짧은 문장/긴 문장 섞기
- 다양한 상황 (보안, 인사, 재무, IT 등)
- 20~30개는 다른 의도와 헷갈릴 수 있는 경계 케이스 포함

양식: {"text": "문장", "label": "judgment"}
한 줄에 하나씩 출력해줘.
```

### 2. 규정 해석 Q&A — 500건

규정에 대해 "이게 무슨 뜻이야?" 같은 질문에 **상세하게 설명해주는** AI를 학습시키는 데이터입니다.
판단(Yes/No)이 아니라 **설명형 답변**입니다.

**양식:**
```json
{
  "instruction": "다음 규정 관련 질문에 대해 상세하게 답변해주세요.",
  "input": "규정 원문 + 질문",
  "output": "설명형 답변"
}
```

**예시:**
```json
{
  "instruction": "다음 규정 관련 질문에 대해 상세하게 답변해주세요.",
  "input": "정보보안 규정 제3조: 최소 권한 원칙에 따라 접근권한을 부여한다.\n\n질문: 최소 권한 원칙이 뭔가요?",
  "output": "최소 권한 원칙은 직원에게 업무 수행에 필요한 최소한의 접근 권한만 부여하는 것입니다.\n\n예를 들어:\n- 개발자라도 담당하지 않는 프로젝트 DB에는 접근 불가\n- 읽기만 필요하면 SELECT 권한만 부여\n\n권한 부여 절차: 부서장 신청 → 보안팀 검토 → 승인 후 IT팀 설정"
}
```

**수집 방법:**
듀듀테크놀로지 규정 문서(`docs/판단예시_1000_듀듀테크놀로지.xlsx`의 조항들)를 참고해서 작성합니다.

ChatGPT에게 아래처럼 요청:
```
아래는 회사 내부 규정이야:
"정보보안 규정 제3조: 최소 권한 원칙에 따라 접근권한을 부여한다."

이 규정에 대해 신입사원이 물어볼 수 있는 Q&A를 10개 만들어줘.

조건:
- input에 반드시 규정 원문을 포함할 것
- output은 친절하고 상세한 설명 (예시 포함)
- 양식: {"instruction": "...", "input": "규정원문\n\n질문: ...", "output": "답변"}
```

> **주의:** input에 반드시 **규정 원문 텍스트**가 포함되어야 합니다. 실서비스에서 RAG가 규정을 자동으로 붙여서 모델에 전달하기 때문입니다.

### 3. 문서 검색 답변 — 200건

RAG(검색엔진)가 찾아온 검색 결과를 바탕으로 **자연스럽게 답변**하는 AI를 학습시키는 데이터입니다.
검색 결과를 그대로 보여주는 게 아니라 정리해서 답변합니다.

**양식:**
```json
{
  "instruction": "다음 검색 결과를 바탕으로 사용자 질문에 답변하세요.",
  "input": "검색 결과 + 질문",
  "output": "정리된 답변"
}
```

**예시:**
```json
{
  "instruction": "다음 검색 결과를 바탕으로 사용자 질문에 답변하세요.",
  "input": "검색 결과:\n1. 정보보안 규정 제3조: 최소 권한 원칙에 따라 접근권한 부여\n2. 인사 규정 제15조: 인턴 및 계약직 시스템 접근 제한\n\n질문: 접근 권한 관련 규정이 뭐가 있어?",
  "output": "접근 권한과 관련된 규정은 크게 두 가지입니다:\n\n1. **정보보안 규정 제3조** — 최소 권한 원칙에 따라 업무에 필요한 최소한의 권한만 부여\n2. **인사 규정 제15조** — 인턴 및 계약직은 정규직보다 제한된 접근 권한 적용\n\n자세한 내용이 필요하시면 말씀해주세요."
}
```

**수집 방법:**
규정 조항들을 조합해서 검색 결과 시나리오를 만들고, 그에 대한 정리된 답변을 작성합니다.

ChatGPT에게 아래처럼 요청:
```
아래 규정 목록에서 2~3개를 골라서 "검색 결과 + 질문 → 정리된 답변" 형태의 데이터를 만들어줘.

규정 목록:
- 정보보안 규정 제3조: 최소 권한 원칙
- 정보보안 규정 제18조: 수습 직원 접근 제한
- 인사 규정 제15조: 인턴 접근 제한
- ...

양식: {"instruction": "...", "input": "검색 결과:\n...\n\n질문: ...", "output": "정리된 답변"}
```

### 4. 문서 요약 — 300건 (동적 필드 방식)

긴 문서를 넣으면 **지정된 필드에 맞게 요약**해주는 AI를 학습시키는 데이터입니다.

**핵심 개념:** input에 **어떤 필드로 요약할지** 목록이 포함됩니다. 모델은 그 필드를 읽고 해당 필드에 맞게 요약합니다. 이렇게 하면 어떤 형태의 요약 요청이든 대응 가능합니다.

**양식:**
```json
{
  "instruction": "주어진 필드에 맞게 문서를 요약하세요.",
  "input": "필드: (요약할 필드 목록)\n\n원본 문서: (긴 문서)",
  "output": { "(필드1)": "내용", "(필드2)": "내용", ... }
}
```

**예시 1 — 보고서 요약:**
```json
{
  "instruction": "주어진 필드에 맞게 문서를 요약하세요.",
  "input": "필드: title, summary, key_points, conclusion\n\n원본 문서:\n제목: 2026년 1분기 보안 감사 보고서\n\n1. 감사 개요\n감사 기간: 2026.01.06 ~ 2026.01.17\n감사 대상: 전사 IT 인프라\n\n2. 주요 발견사항\n- 퇴사자 계정 미삭제 12건\n- 외부 접근 차단 정상 작동\n- 레거시 DB 암호화 미적용 3건\n\n3. 종합 평가\n전반적 보안 수준 B+ 등급",
  "output": {
    "title": "2026년 1분기 보안 감사 보고서",
    "summary": "전반적 보안 수준 B+ 평가. 퇴사자 계정 미삭제, 레거시 DB 암호화 미적용 등 일부 개선 필요",
    "key_points": "- 퇴사자 계정 미삭제 12건 발견\n- 외부 침입 시도 전부 차단 성공\n- 레거시 DB 암호화 미적용 3건",
    "conclusion": "계정 삭제 자동화 시스템 도입 및 레거시 DB 암호화 작업 필요"
  }
}
```

**예시 2 — 기획서 요약:**
```json
{
  "instruction": "주어진 필드에 맞게 문서를 요약하세요.",
  "input": "필드: title, background, summary, key_points\n\n원본 문서:\n제목: 사내 챗봇 도입 기획서\n\n1. 배경\n반복 업무 문의가 월 500건 이상 발생하여 업무 효율이 저하되고 있음...\n\n2. 제안\nAI 기반 사내 챗봇을 도입하여 규정 질문, 일정 관리 등을 자동화...\n\n3. 기대 효과\n문의 처리 시간 70% 단축 예상",
  "output": {
    "title": "사내 챗봇 도입 기획서",
    "background": "반복 업무 문의 월 500건 이상으로 업무 효율 저하",
    "summary": "AI 사내 챗봇을 도입하여 규정 질문, 일정 관리 등 반복 업무를 자동화하는 기획",
    "key_points": "- 반복 문의 월 500건 자동화 대상\n- 규정 질문, 일정 관리 등 핵심 기능\n- 문의 처리 시간 70% 단축 기대"
  }
}
```

**필드 조합을 다양하게 섞어야 합니다:**

| 필드 조합 | 건수 | 설명 |
|----------|:----:|------|
| title, summary, key_points, conclusion | 80 | 보고서형 |
| title, summary, key_points, action_required | 60 | 감사/점검형 |
| title, background, summary, key_points | 60 | 기획서형 |
| title, summary, recipients, action_required | 50 | 공지/메일형 |
| title, summary, key_points, technical_details | 50 | 기술문서형 |

**수집 방법:**
```
한국 IT 기업의 "주간 업무 보고서"를 1000자 분량으로 작성하고,
아래 필드에 맞게 요약을 만들어줘.

필드: title, summary, key_points, conclusion

양식:
{
  "instruction": "주어진 필드에 맞게 문서를 요약하세요.",
  "input": "필드: title, summary, key_points, conclusion\n\n원본 문서: (작성한 보고서)",
  "output": {"title": "...", "summary": "...", "key_points": "...", "conclusion": "..."}
}
```

### 5. 문서 생성 — 200건 (동적 필드 방식)

요구사항을 주면 **지정된 필드에 맞게 문서를 생성**하는 AI를 학습시키는 데이터입니다.

**핵심 개념:** input에 **템플릿 이름 + 필드 목록**이 포함됩니다. 모델은 필드 목록을 읽고 각 필드에 맞는 내용을 생성합니다. 이렇게 하면 어떤 템플릿이든 대응 가능합니다.

두 가지 유형이 있습니다.

#### 유형 A: 짧은 요구사항 → 필드별 생성 (100건)

사용자가 간단한 요구사항을 주면, 각 필드를 채워서 문서를 생성합니다.

```json
{
  "instruction": "주어진 템플릿 필드에 맞게 각 항목을 작성하세요.",
  "input": "템플릿: 채용공고\n필드: position, employment_type, experience, responsibilities, requirements, preferred, benefits\n\n요구사항: 프론트엔드 개발자, 2년차, React, 재택 가능",
  "output": {
    "position": "프론트엔드 개발자",
    "employment_type": "정규직",
    "experience": "2년 이상",
    "responsibilities": "- React 기반 웹 서비스 개발 및 유지보수\n- UI/UX 개선 및 성능 최적화\n- 백엔드 API 연동",
    "requirements": "- React 실무 경력 2년 이상\n- JavaScript/TypeScript 능숙\n- Git 기반 협업 경험",
    "preferred": "- Next.js 경험\n- 디자인 시스템 구축 경험",
    "benefits": "- 재택근무 주 2회\n- 자기개발비 연 100만원"
  }
}
```

#### 유형 B: 긴 원본 → 템플릿 필드별 재구성 (100건)

사용자가 긴 원본 문서를 주면, 템플릿 필드에 맞게 재구성합니다.

```json
{
  "instruction": "주어진 템플릿 필드에 맞게 문서를 재구성하세요.",
  "input": "템플릿: 보고서\n필드: title, date, author, summary, content, conclusion\n\n원본 문서:\n지난주 개발팀에서 보안 감사를 진행했습니다. 총 42개 항목을 점검했으며 3건의 보안 취약점이 발견되어 긴급 패치를 완료했습니다. 다음 분기에는 자동화 도구를 도입할 예정입니다.",
  "output": {
    "title": "보안 감사 결과 보고서",
    "date": "",
    "author": "",
    "summary": "전사 보안 감사 42개 항목 점검, 취약점 3건 발견 및 긴급 패치 완료",
    "content": "## 점검 결과\n- 점검 항목: 42개\n- 발견 취약점: 3건\n- 조치: 긴급 패치 완료\n\n## 향후 계획\n- 다음 분기 자동화 도구 도입 예정",
    "conclusion": "현재 보안 이슈는 모두 해결됨. 자동화 도구 도입으로 지속적 모니터링 체계 구축 필요"
  }
}
```

**4개 시스템 템플릿별 필드 참고표:**

| 템플릿 | 필드 목록 | A | B |
|--------|----------|:-:|:-:|
| 회의록 | title, date, attendees, agenda, content, decisions, action_items | 25 | 25 |
| 보고서 | title, date, author, summary, content, conclusion | 25 | 25 |
| 채용공고 | position, employment_type, experience, responsibilities, requirements, preferred, benefits | 25 | 25 |
| 제안서 | title, background, content, expected_results, timeline, resources | 25 | 25 |

**수집 방법:**
```
한국 IT 기업에서 사용하는 채용공고(JD)를 만들어줘.

양식:
{
  "instruction": "주어진 템플릿 필드에 맞게 각 항목을 작성하세요.",
  "input": "템플릿: 채용공고\n필드: position, employment_type, experience, responsibilities, requirements, preferred, benefits\n\n요구사항: (간단한 조건)",
  "output": {"position": "...", "employment_type": "...", ...}
}

다양한 포지션으로 25개 만들어줘. (백엔드, 프론트, 데이터, PM, 디자이너 등)
```

### 6. 리스크 감지 — 200건

회의 내용이나 문서에서 **회사 규정 위반 가능성**을 찾아내는 AI를 학습시키는 데이터입니다.
위반 있음 100건 + 위반 없음 100건으로 균등하게 만듭니다.

**양식:**
```json
{
  "instruction": "다음 내용에서 규정 위반 여부를 감지하세요.",
  "input": "회의/문서 내용 + 관련 규정",
  "output": {
    "risk_detected": true,
    "risk_level": "high|medium|low",
    "violation": "위반한 규정 조항",
    "detail": "구체적 위반 내용",
    "recommendation": "권고 사항"
  }
}
```

**위반 있는 경우 예시:**

## 주의사항

1. **output이 JSON인 데이터 (2~6번)는 반드시 JSON 양식을 지켜주세요.** 필드명이 다르면 학습이 안 됩니다.
2. **규정 관련 데이터 (2, 3, 6번)는 input에 규정 원문을 반드시 포함해주세요.**
3. **다양성이 중요합니다.** 같은 패턴만 200개 만들면 모델이 편향됩니다. 상황/문체/길이를 다양하게 섞어주세요.
4. **경계 케이스도 포함해주세요.** 예: "연차 규정에 따라 내일 쉬어도 돼?" — 이건 judgment일까 doc_search일까? 이런 애매한 문장이 20~30건씩 필요합니다.
5. **문서 요약/생성 (4, 5번)은 input에 `필드:` 줄이 반드시 포함되어야 합니다.** 이 필드 목록을 보고 모델이 output을 생성합니다.
6. ChatGPT/Claude로 생성 후 **반드시 검수**해주세요. AI가 양식을 틀리거나 내용이 부자연스러운 경우가 있습니다.
