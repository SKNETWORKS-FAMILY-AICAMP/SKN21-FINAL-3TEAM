2026년 1분기 AI 문서 에이전트 개발 업무 보고

보고 부서: AI 개발팀
보고자: 진승언 (AI 리드)
보고 대상: 개발본부장
보고 유형: 수시

이번 보고는 WorkFlow AI 서비스의 핵심 기능인 문서 생성 에이전트 개발 완료에 따른
주요 성과 및 향후 계획을 정리한 수시 보고서입니다.

주요 완료 사항:
- LangGraph 기반 멀티에이전트 아키텍처 설계 및 구현 완료
- 회의록, 업무보고서, 제안서 3종 DOCX 자동 생성 기능 구현
- Solar LLM API 연동 및 문서 구조화 프롬프트 최적화 완료
- FastAPI 문서 생성 엔드포인트 구현 (POST /generate, GET /{id}/download)
- python-docx 기반 서식 개선 (파란 색상 테마, 섹션 헤더 스타일링)
- UUID 기반 파일 관리 및 백엔드 generated_docs 디렉토리 구조 정립

진행 중인 사항:
- RAG 파이프라인 구축 (Qdrant 벡터 DB 연동, BM25 하이브리드 검색)
- 문서 파서 고도화 (Docling 기반 PDF/DOCX 텍스트 추출 정확도 개선)
- 인텐트 분류기 임계값 튜닝 (현재 confidence 낮은 케이스 다수 발생)

이슈사항:
- LLM 응답 생성 시간이 평균 4~6초로 UX 개선 필요
- 일부 회의록 요약이 한 줄로 짧게 생성되는 현상 → 프롬프트 수정으로 개선 완료
- 인텐트 분류 신뢰도가 낮을 경우 사용자에게 후보 노출되는 UX 이슈 검토 필요

다음 분기 계획:
- sLLM 파인튜닝을 위한 학습 데이터 수집 시작 (문서 생성 입력/출력 쌍)
- Qdrant 기반 문서 RAG 검색 기능 완성 및 통합 테스트
- vLLM 서빙 환경 구축 (RunPod A100 활용)
- AWS EC2/S3/RDS 배포 환경 구성
