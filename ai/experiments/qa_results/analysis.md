## 2. A.X가 높은 핵심 이유

### 2-1. 답변 스타일: 간결 vs 장황

A.X는 핵심 정보만 추출해 짧게 답하는 반면, Midm은 질문을 반복하고 부연 설명을 붙인다.

| ID | 질문 | Gold | Midm 예측 | A.X 예측 |
|----|------|------|-----------|----------|
| gen_002 | 광합성 부산물은? | 산소 | 광합성 과정에서 부산물로 방출되는 물질은 **산소**입니다. | 산소 |
| gen_007 | 파리협정 체결 연도? | 2015년 | 파리협정은 2015년에 체결되었습니다. | 2015년 |
| gen_010 | 태양에 가장 가까운 행성? | 수성 | 태양계에서 태양과 가장 가까운 행성은 **수성**입니다. | 수성 |
| biz_011 | 2분기 목표 달성률? | 94.1% | 2분기 목표 달성률은 94.1%입니다. | 94.1% |

**Token F1 영향**: Midm의 경우 예측 토큰 수가 많아질수록 Precision이 낮아져 TF1이 하락한다.

```
gen_007 Midm:
  Gold 토큰: ["2015년"]
  Pred 토큰: ["파리협정은", "2015년에", "체결되었습니다"]
  공통: 0개 ("2015년" ≠ "2015년에")
  TF1 = 0.0

gen_007 A.X:
  Gold 토큰: ["2015년"]
  Pred 토큰: ["2015년"]
  공통: 1개
  TF1 = 1.0
```

### 2-2. 마크다운 볼드(`**text**`) 사용

Midm은 거의 모든 답변에 `**bold**` 마크다운을 사용한다. `normalize_answer`가 특수문자를 제거하지만 `**` 안의 텍스트가 토큰으로 분리되어 매칭 실패가 발생한다.

| ID | Gold | Midm 예측 | Midm ROUGE-L |
|----|------|-----------|:---:|
| gen_003 | 훈민정음 | 세종대왕이 창제한 문자 체계의 이름은 **훈민정음**입니다. | 0.0 |
| gen_004 | 사건 지평선 | 블랙홀에서 빛이 탈출하지 못하는 경계를 **사건 지평선**이라고 합니다. | 0.0 |
| gen_010 | 수성 | 태양계에서 태양과 가장 가까운 행성은 **수성**입니다. | 0.0 |
| gen_011 | 왓슨과 크릭 | DNA 이중 나선 구조를 규명한 과학자들은 **왓슨(Watson)과 크릭(Crick)**입니다. | 0.0 |

A.X는 `**` 없이 깔끔하게 답해 이 문제가 없다.

### 2-3. 일반 도메인(general)에서의 격차

일반 Token F1이 Midm 0.2375 vs A.X 0.8663으로 가장 큰 격차를 보인다.

일반 도메인 질문은 단답형(연도, 이름, 단어)이 많아 간결하게 답할수록 유리하다.
A.X는 단답형 질문에 핵심 단어만 반환하는 반면, Midm은 항상 완전한 문장으로 답한다.

```
gen_009 조선왕조실록 유네스코 등재 연도:
  Gold: "1997년"
  Midm: "조선왕조실록이 유네스코 세계기록유산으로 등재된 연도는 1997년입니다."  → TF1=0.0
  A.X : "1997년"  → TF1=1.0
```

## 3. A.X의 약점

### 3-1. biz_007 오답 (유일한 완전 오답)

| | 내용 |
|--|------|
| 질문 | 고객사가 요청한 기술지원 SLA 응답 시간은? |
| Gold | 8시간 |
| A.X 예측 | **4월 4일까지 회신 예정** |
| TF1 / ROUGE-L | 0.0 / 0.0 |

지문에 "SLA 단축 요청(8시간)"과 "SLA 변경 검토 후 회신(4/4)"이 함께 있는데, A.X가 후속 조치 날짜를 SLA 응답 시간으로 혼동했다. Midm은 "8시간"으로 정확히 답했다(TF1=0.18, ROUGE-L=0.5).

### 3-2. 부분 답변 누락

| ID | Gold | A.X 예측 | 비고 |
|----|------|----------|------|
| gen_018 | 태양광, 풍력, 수력, 지열, 바이오매스 등 | 태양광, 풍력, 수력 | 3가지만 나열 |
| biz_013 | 3개월 (4월부터 7월 재평가까지) | 3개월입니다. | 기간 세부사항 누락 |

간결함을 추구하다 일부 정보가 빠지는 경우가 있다.

---

### 3-3. ROUGE-L이 낮은 단답형 케이스

A.X의 단답형 답변("수성", "큐비트", "산소" 등)에서 ROUGE-L=0.0이 다수 관찰된다.
이는 `rouge_score` 라이브러리가 영어 중심 설계라 한국어 단일 토큰의 LCS 계산이 불안정하기 때문이다.
실제로는 정답임에도 ROUGE-L이 0으로 측정되는 **지표 측정의 한계**로 봐야 한다.

```
A.X gen_010: Gold="수성", Pred="수성" → TF1=1.0, ROUGE-L=0.0  (실제는 정답)
A.X gen_016: Gold="큐비트", Pred="큐비트" → TF1=1.0, ROUGE-L=0.0  (실제는 정답)
```

## 4. Midm의 강점

### 4-1. 복잡한 질문에서 더 풍부한 답변

설명을 요구하는 질문에서 Midm은 더 상세한 답변을 생성한다.

```
gen_013 GDP와 GNP의 차이:
  Midm: "GDP는 지리적 위치(영토 내 생산)를 기준으로 하고,
         GNP는 국적(국민의 생산 활동)을 기준으로 합니다."
        → 추가 설명 포함, 정성적으로 더 우수

gen_019 헌법 개정 배경:
  Midm: "이 운동은 대통령 직선제 부활을 요구하는 민주화 운동이었고,
         그 결과로 제9차 개헌이 이루어져..."
        → 맥락 설명 포함
```

지표상으로는 낮지만, 실제 사용자 경험에서는 더 유용할 수 있는 케이스다.

### 4-2. biz_007 정확도

A.X가 혼동한 SLA 질문에서 Midm은 "8시간"을 정확히 포함했다.

## 6. 결론 및 베이스 모델 선정

**→ A.X-3.1-Light 선정**

| 기준 | 평가 |
|------|------|
| 정확도 (TF1) | A.X 우세 (0.75 vs 0.32) — 단, 답변 형식 차이에 기인 |
| 정확도 (ROUGE-L) | A.X 소폭 우세 (0.66 vs 0.61) — 동일한 형식 효과 |
| 정성 평가 | A.X 약점 존재 (biz_007 완전 오답 등) — 실질 정확도 격차는 크지 않음 |
| 추론 속도 | A.X 5.7배 빠름 (0.55s vs 3.13s) |
| VRAM 효율 | A.X fp16 14GB < Midm 4-bit 7.6GB (절대값은 Midm 우세, but A.X도 L4 수용 가능) |

### 선정 근거

정량 지표(TF1, ROUGE-L)에서 A.X가 높게 나타나지만, 이는 모델의 실질적인 정확도 차이보다 **답변 형식(단답형 vs. 완전 문장)**의 차이에 크게 기인한다. Midm은 항상 완전한 문장으로 답하는 반면, TF1·ROUGE-L은 간결한 단답형에 유리한 지표이기 때문이다.

정성 평가 측면에서는 오히려 A.X가 biz_007처럼 답변을 완전히 틀리는 경우가 있어, 실질 정확도 면에서 두 모델의 격차는 지표만큼 크지 않다.

그럼에도 **A.X-3.1-Light를 파인튜닝 베이스 모델로 선정**하는 이유는 **추론 속도의 압도적 우위(5.7배)** 때문이다. 서비스 응답성을 고려할 때 이 차이는 결정적이며, 정성 평가에서 드러난 오답 유형(복수의 날짜·수치 혼재 문서 등)은 파인튜닝 데이터 구성으로 보완 가능하다.

## 7. 지표 한계 및 주의사항

- **Token F1**: 한국어 어절 단위 분리로 `입니다`가 붙은 토큰은 별도 토큰으로 처리 → 정답임에도 낮게 측정되는 케이스 존재
- **ROUGE-L**: `rouge_score` 라이브러리의 한국어 단일 토큰 처리 불안정 → 동일한 단답도 0.0이 나오는 경우 있음
- 두 지표 모두 **형식보다 내용 일치**를 평가하는 데 한계가 있으므로 정성 분석(섹션 3~4)을 함께 참조할 것
