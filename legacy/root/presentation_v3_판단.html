08-1

4중 보조장치 (Guardrail)

sLLM은 환각을 만든다 — RAG 원본과 대조하여 4단계 검증

검증 단계별 상세

1

판단 카테고리 제한

LLM 출력이 yes / no / conditional / no_regulation 4가지 외의 값이면 자동 대체

위반 시: Confidence → min(raw, 0.3)

2

규정 키워드 매칭

LLM이 인용한 조항이 RAG 검색 결과에 실제 존재하는지 매칭률(0~1.0) 산출

감점: (0.5 - match_ratio) × 0.3

3

조항 존재 검증

"제N조"로 인용한 조항을 Qdrant DB에서 직접 검색, 미존재 시 환각 플래그

감점: 0.05 × missing_count

4

일관성 모니터링

동일 쿼리 캐싱(max 500건 FIFO), 같은 질문에 다른 결과 나오면 경고

flag만 부여 (감점 없음)

환각 탐지 예시

sLLM 출력 (검증 전)

regulations: "제12조"

confidence: 0.92

3 Qdrant에서 "제12조" 검색 → 미존재 (환각)
2 RAG 결과 매칭률 → 0.0 (불일치)

보정 후 출력

confidence: 0.92 → 0.25 (Hard Cap 적용)

hallucination_flag: true

5-Factor Confidence 보정

Base = LLM_raw × 0.60 + RAG_score × 0.25 + 규정커버리지 × 0.15

− 규정 충돌 감점 (0.1/건)

− 키워드 매칭 감점

− 미존재 조항 감점 (0.05/건)

Hard Cap: RAG 품질 < 0.2 → max 0.4 · 키워드 매칭 < 0.2 → max 0.3 · 인용 전부 미존재 → max 0.25

4중 보조장치 (Guardrail)

• 규정 키워드 매칭 (매칭률 0~1.0)

• 인용 조항 존재 검증 (환각 차단)

• 카테고리 제한 (yes/no/cond 외 차단)

• 일관성 모니터링 (500건 FIFO 캐시)

5-factor Confidence 보정

LLM raw × 0.60 + RAG score × 0.25 + 커버리지 × 0.15

• 규정 충돌 시 감점 (-0.1/건)

• 키워드 매칭 < 0.2 → max 0.3

• 인용 전부 미존재 → max 0.25

Base: confidence 항상 0.9+ (과신) → 보정 후: 0.25~0.85 범위로 현실 반영
