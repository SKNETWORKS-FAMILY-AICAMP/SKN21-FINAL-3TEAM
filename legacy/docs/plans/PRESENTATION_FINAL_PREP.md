| 순서 | 발표 내용 | 청중 심리 |
|------|----------|----------|
| 슬라이드 04~05 | 페르소나: GPT 못 쓰는 회사 | "아, sLLM이 필요하겠구나" |
| 슬라이드 11 | Base 한계 (정확도 37%, 환각) | "근데 sLLM도 안 되는 거 아냐?" |
| 슬라이드 13 | LoRA 성과 (85.4%, 91%, 100%) | "오 되네. 근데 진짜?" |
| **▶ 영상** | 실제 채팅 동작 시연 | **"진짜 되네"** ← 임팩트 극대화 |

## 3. 서비스 페르소나

### 3-1. 기업 프로필

| 항목 | 내용 |
|------|------|
| **회사명** | (가상) 세진테크 |
| **업종** | 제조·IT 복합 중견기업 (자동차 부품 + 자체 MES 솔루션) |
| **규모** | 직원 350명 / 매출 1,200억 / 본사 판교, 공장 화성 |
| **특징** | 대기업 2~3곳에 납품. 납품사 보안 심사를 매년 통과해야 함 |

### 3-2. 왜 이 회사는 GPT를 쓸 수 없는가

| 제약 | 상세 |
|------|------|
| **납품사 보안 요구** | 현대·삼성 등 대기업 납품 시 **정보보안 서약서** 작성. "협력사 내부 데이터를 외부 클라우드 AI에 전송하지 않겠다"는 조항 포함. 위반 시 **거래 중단** |
| **ISMS 인증 유지** | 연매출 100억 이상 IT기업은 ISMS 인증 의무. 외부 AI에 내부 규정·기술 데이터 전송 시 **인증 심사에서 결함** 판정 가능 |
| **영업비밀 유출 리스크** | 자체 MES 솔루션의 기술 규격, 단가표, 거래처 정보가 규정 질의에 포함될 수 있음. GPT로 보내면 **영업비밀 유출** |
| **예산 한계** | 대기업처럼 Azure OpenAI 전용 인스턴스(월 수천만 원)를 구축할 여력 없음. 그렇다고 GPT API 종량제를 350명이 쓰면 **월 200~500만 원** |

> **핵심**: 대기업만큼 보안이 필요한데, 대기업만큼 돈은 없다. → **sLLM이 유일한 해법**

### 3-3. 페르소나: 경영지원팀 신지용 대리

| 항목 | 내용 |
|------|------|
| **이름** | 신지용 (31세) |
| **직급** | 세진테크 경영지원팀 대리 (4년차) |
| **역할** | 인사·총무·규정 관리를 **혼자** 담당 (중견기업 특유의 1인 다역) |

#### 하루 일과와 고충

| 시간 | 업무 | 고충 |
|------|------|------|
| 09:00 | 출근. 메일함에 규정 문의 5건 | "해외출장 시 법인카드 한도가 얼마야?", "협력사 NDA 규정 어디 있어?" — 매번 500페이지 사규집 뒤적임 |
| 10:00 | 어제 품질회의 회의록 작성 | 양식이 매번 달라서 팀장한테 퇴짜. 30분 걸리는 걸 2번 작성 = 1시간 |
| 11:00 | 납품사 보안 심사 대응 자료 준비 | "GPT 사용 여부" 확인란에 "사용 안 함" 체크해야 함. 쓰면 **거래 중단** |
| 14:00 | 팀 미팅 일정 조율 | 캘린더 확인 → 메일 발송 → Meet 링크 생성 → 할 일 등록, 4개 앱 왔다갔다 |
| 16:00 | 신규 입사자가 질문 | "인턴도 보안구역 출입 가능해요?" — 보안규정 찾느라 20분, 확신 없어서 보안팀에 또 확인 |
| 18:00 | 야근. 내일 제출할 보고서 작성 | ChatGPT 쓰고 싶지만 **사내 데이터 넣으면 ISMS 위반**. 결국 수작업 |

#### 신지용 대리의 한 마디

> "ChatGPT가 얼마나 편한지 알아요. 집에서는 매일 써요.
> 근데 회사에서는 **쓸 수가 없어요**.
> 납품사 보안 심사에서 'AI에 데이터 전송한 적 있냐' 물어보는데, 있다고 하면 거래 끊겨요.
> 그렇다고 Azure OpenAI 전용 구축? 우리 회사 규모에 **월 천만 원짜리 솔루션**은 말이 안 돼요.
> 우리 회사 규정에 맞게 답해주는 AI가 **사내 서버 안에서** 돌아가면 좋겠어요."

### 3-4. DUDE sLLM이 이 회사에 답인 이유

| 신지용의 고충 | DUDE 해결 | sLLM이 필수인 이유 |
|-------------|----------|------------------|
