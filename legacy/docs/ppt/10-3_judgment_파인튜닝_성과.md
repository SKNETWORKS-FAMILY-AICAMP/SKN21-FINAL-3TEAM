# 10-3. 판단 Agent 파인튜닝 + 성과 (1페이지)

> 슬라이드 제목: **판단 Agent 파인튜닝** | 부제: Kanana-1.5-8B + LoRA | Base 37.2% → 최종 85.4% (+48.2%p)

---

### 3단계 실험 (좌측 — 바 차트 or 흐름도)

| 단계 | 실험 | 정확도 | 핵심 |
|------|------|--------|------|
| Base | 파인튜닝 전 | 37.2% | 기준점 |
| **1. 성공** | v1 하드코딩 3ep | **86.6%** | +49.4%p, 최초 파인튜닝 |
| 2-a. 실패 | v2 +98건 보강 | 83.4% | 데이터 양 늘렸으나 라벨 품질 낮아 -3.2%p |
| 2-b. 실패 | v1 RAG 전환 | 76.8% | RAG 노이즈로 -9.8%p, conditional 84→55% |
| **3. 극복** | v3 19건 정밀 보강 | **85.4%** | 재량표현 14건 + 경계 5건 타겟 추가 |
