## 3. 파인튜닝 데이터 예시

### Generate 예시 — 회의록

**System Prompt:**
```
당신은 기업 문서 작성 전문가입니다.
사용자가 제공하는 [필드 명세]에 따라 문서 내용을 JSON으로 생성하세요.

규칙:
- [필드 명세]에 정의된 필드만 JSON 키로 사용하세요.
- 각 필드의 설명을 참고하여, 입력 내용을 바탕으로 구체적인 문서 내용을 작성하세요.
- 필드 설명이나 지침 문장을 그대로 값으로 출력하지 마세요.
- 입력 내용에 해당 정보가 없으면 빈 문자열 또는 빈 배열로 두세요.
- 배열 필드는 반드시 JSON 배열 형태로 출력하세요.
- 반드시 JSON만 출력하세요. 설명 텍스트나 마크다운을 포함하지 마세요.
```

**User Input:**
```
다음 내용을 바탕으로 문서를 JSON 형식으로 작성해주세요.

[문서 유형] 회의록

[필드 명세]
- title: 회의 주제를 반영한 구체적인 제목
- date: 회의 날짜 (YYYY-MM-DD 형식)
- attendees: 참석자 이름 배열
- content: 회의 내용을 상세하게 기술
- summary: 주요 내용을 3~5문장으로 요약
- decisions: 결정된 사항 목록 (배열)

[회의 내용]
2023년 11월 15일, 서울 본사에서 열린 자동차 부문 예산 심의 회의...
```

**Assistant Output (학습 정답):**
```json
{
    "title": "2024년 회계연도 예산 심의 회의",
    "date": "2023-11-15",
    "attendees": ["김성훈 부사장", "이준혁 재무 팀장", "박소라 마케팅 총괄", "최민수 생산 관리자"],
    "content": "2023년 11월 15일, 서울 본사에서 열린 자동차 부문 예산 심의 회의가...",
    "summary": "2024년 회계연도 예산안을 심의하고 부서별 예산 할당을 논의했다...",
    "decisions": ["마케팅 예산 15% 증액", "생산라인 자동화 투자 승인"]
}
```
