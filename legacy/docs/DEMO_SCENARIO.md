# DUDE 데모 시나리오 (촬영용)

> 목표: 5분 내외 · 넉넉하게 촬영 후 편집으로 맞추기
> SSE 응답 대기는 편집으로 컷 · 씬 4~5는 같은 채팅 세션 연속 촬영

---

## 씬 1. 로그인 + 대시보드 (25초)

> **멘트**: "DUDE는 사내 규정, 문서, 일정을 하나의 채팅으로 처리하는 Multi-Agent 워크스페이스입니다. 로그인하면 대시보드에서 오늘의 업무 현황을 한눈에 볼 수 있고, 위젯을 자유롭게 배치할 수 있습니다."

| 순서 | 동작 | 포인트 |
|:---:|------|--------|
| 1 | 로그인 페이지 → ID/PW 입력 → 로그인 | 깔끔한 UI 첫인상 |
| 2 | 대시보드 도착 → 위젯 훑기 | 일정 타임라인, 최근 문서, 태스크 파이프라인, AI 채팅 위젯, 승인 대기열 |
| 3 | 위젯 편집 모드 → 드래그 드롭으로 위젯 재배치 | 커스터마이즈 가능 강조 |

**촬영 팁**: 대시보드에 데이터가 채워진 상태로 촬영. 위젯 편집은 1~2초만 보여주고 빠르게 넘기기

## 씬 2. 규정 판단 — Judgment Agent (60초)

> 4가지 판단 유형(yes/no/conditional/no_regulation) 전부 시연

> **멘트 (도입)**: "먼저 판단 Agent입니다. 사내 규정에 대한 질문을 하면, AI가 RAG로 관련 규정을 검색하고, 4중 보조장치로 환각을 검증한 뒤 판단 결과를 제공합니다. 4가지 판단 유형을 모두 보여드리겠습니다."

| 순서 | 동작 | 멘트 (자막) |
|:---:|------|--------|
| 1 | 채팅 페이지 이동 → 새 대화 생성 | |
| 2 | **conditional** — `"인턴에게 AWS 콘솔 접근 권한을 줘도 되나요?"` | |
| 3 | JudgmentCard 확인 | **"조건부 허용 — 보안교육 이수와 부서장 승인이 필요하다고 판단했습니다. 정보보안규정 제25조를 근거로 인용하고 있고, 신뢰도도 적절하게 보정됐습니다."** |
| 4 | **yes** — `"재택근무 시 VPN 접속이 필수인가요?"` | |
| 5 | JudgmentCard 확인 | **"이번엔 명확하게 yes. 규정에 VPN 필수 사용이 명시되어 있습니다."** |
| 6 | **no** — `"공용 Wi-Fi에서 업무 시스템에 접속해도 되나요?"` | |
| 7 | JudgmentCard 확인 | **"no — 외부 저장매체 사용 금지 규정이 있습니다."** |
| 8 | **no_regulation** — `"점심시간에 회사 근처 헬스장 다녀도 되나요?"` | |
| 9 | JudgmentCard 확인 | **"해당 사항을 다루는 규정이 없다고 정직하게 답변합니다. Base 모델은 이 no_regulation 인식률이 6%였지만, LoRA 파인튜닝 후 97%까지 올렸습니다."** |

> **멘트 (마무리)**: "이렇게 yes, no, 조건부, 규정 없음 — 4가지 유형을 모두 구분하며, LLM이 지어낸 조항이 아닌 실제 존재하는 규정만 인용합니다."

**촬영 팁**: 스트리밍 시작 → 점프컷 → 완성 카드로 편집. 4개 결과 뱃지 색상 차이가 핵심

## 씬 3. 문서 관리 — 업로드/검색/상세 (30초)

> **멘트**: "문서 관리 페이지입니다. 문서를 업로드하면 AI가 자동으로 카테고리, 태그, 요약을 생성합니다. 별도 분류 작업 없이 드래그앤드롭만 하면 됩니다."

| 순서 | 동작 | 멘트 (자막) |
|:---:|------|--------|
| 1 | 문서 페이지 이동 → 문서 목록 확인 | |
| 2 | PDF 또는 DOCX 드래그앤드롭 업로드 | |
| 3 | AI 자동 분류 결과 확인 | **"업로드 즉시 v3_summary LoRA가 분류와 요약을 자동으로 생성합니다."** |
| 4 | 키워드 검색 → 하이라이트 결과 | **"BM25 + Vector 하이브리드 검색으로 키워드와 의미 모두 잡습니다."** |
| 5 | **문서 클릭 → 상세 페이지** | **"상세 페이지에서 문서 미리보기와 AI 요약을 함께 확인할 수 있습니다."** |

**촬영 팁**: 업로드 후 자동 분류되는 순간을 놓치지 말기

## 씬 4. 문서 QA + 요약 — Document Agent (35초)

> 씬 4~5는 같은 채팅 세션에서 연속 촬영

> **멘트 (도입)**: "이번엔 문서 Agent입니다. 채팅으로 문서를 검색하고, 질문하고, 요약할 수 있습니다."

| 순서 | 동작 | 멘트 (자막) |
|:---:|------|--------|
| 1 | 채팅에서 검색: `"보안 관련 문서 검색해줘"` | |
| 2 | 검색 결과 카드 확인 | **"검색은 LLM을 호출하지 않아 가장 빠릅니다. 관련도 점수와 함께 결과를 보여줍니다."** |
| 3 | QA 질문: `"클라우드 관련 계약 내용 자세히 알려줘"` | |
| 4 | DocumentCard 확인 | **"QA는 RAG로 관련 문서를 찾고, sLLM이 여러 문서를 종합해서 답변합니다. 출처도 함께 표시됩니다."** |
| 5 | follow-up: `"위 문서에서 계약 기간은 언제부터 언제까지야?"` | **"이전 대화 맥락을 유지한 채 후속 질문이 가능합니다."** |
| 6 | 요약 요청: `"문서 요약해줘"` → 문서 선택 | **"요약은 7개 분류 체계에 맞게 분류하고, 핵심만 132자로 간결하게 정리합니다."** |

## 씬 5. 문서 자동 생성 — Document Agent (45초)

> **멘트 (도입)**: "이제 문서 자동 생성입니다. 채팅으로 내용만 말하면 회의록, 보고서, 제안서를 자동으로 작성합니다."

| 순서 | 동작 | 멘트 (자막) |
|:---:|------|--------|
| 1 | 채팅에서: `"회의록 생성해줘"` → 듀듀가 내용 요청 | |
| 2 | 내용 입력 (시연_문서agent_챗봇.md 시나리오 2 텍스트 사용) | |
| 3 | GenerateCard 확인 | **"v3_generate LoRA가 참석자, 결정사항 3건, 액션아이템 4건을 자동으로 추출했습니다. Base 모델은 이 필드를 34%만 채웠지만, 파인튜닝 후 100%입니다."** |
| 4 | DOCX 다운로드 → 파일 열기 | **"실제 Word 문서로 다운로드됩니다."** |
| 5 | **"선택한 일정 등록"** 클릭 | **"액션아이템에서 추출된 일정을 바로 캘린더와 파이프라인에 등록할 수 있습니다. 문서 생성에서 일정 관리까지 하나의 워크플로우로 연결됩니다."** |
| 6 | **문서 생성 전용 페이지** 이동 | **"채팅 외에도 전용 페이지에서 템플릿을 선택해서 생성할 수 있습니다. 커스텀 Word 양식도 업로드해서 사용 가능합니다."** |

**촬영 팁**: 경로A(챗봇) → 경로B(전용 페이지) 두 가지 모두 시연

## 씬 6. 일정 등록 + 캘린더 — Schedule Agent (45초)

> **멘트 (도입)**: "일정 Agent입니다. 자연어로 일정을 등록하면 Google Calendar에 자동 동기화되고, 후속 작업까지 제안합니다."

| 순서 | 동작 | 멘트 (자막) |
|:---:|------|--------|
| 1 | 채팅에서: `"내일 오후 3시에 팀 회의 잡아줘"` | |
| 2 | ScheduleConfirmCard → 확인 클릭 | **"자연어에서 날짜와 시간을 자동 파싱합니다."** |
| 3 | ScheduleCard 결과 | **"Google Calendar에 즉시 동기화됩니다."** |
| 4 | 후속: "Meet 링크 생성할까요?" → `"응"` | **"회의 등록 후 Meet 링크 생성, 초대 메일 발송까지 자동 제안합니다."** |
| 5 | **일정 페이지 → calendar 탭** | **"캘린더에서 방금 등록한 일정을 바로 확인할 수 있습니다."** |
| 6 | **pipeline 탭** | **"파이프라인에서는 칸반 보드로 태스크를 관리합니다. 드래그 드롭으로 스테이지를 변경할 수 있습니다."** |
| 7 | **approvals 탭** | **"결재 탭에서는 승인 대기 요청을 확인하고 처리할 수 있습니다."** |
| 8 | **sheets 탭** | **"Google Sheets로 프로젝트를 내보내면 WBS, Gantt 차트, 대시보드가 자동 생성됩니다."** |

**촬영 팁**: 4개 탭 순서대로 빠르게 전환

## 씬 7. 복합 질문 — Planner Agent (30초)

> **멘트 (도입)**: "마지막 핵심 기능, Planner Agent입니다. 여러 가지 요청을 한 문장에 하면 자동으로 분해해서 처리합니다."

| 순서 | 동작 | 멘트 (자막) |
|:---:|------|--------|
| 1 | 채팅에서: `"연차 규정 확인하고 이번주 일정 보고 비는 날에 휴가 등록해줘"` | |
| 2 | Planner 분해 확인 | **"하나의 문장을 3개 스텝으로 분해합니다. 규정 확인 → 일정 조회 → 휴가 등록 순서로, 앞 단계 결과가 다음 단계에 반영됩니다."** |
| 3 | 각 Agent 결과 순차 도착 | **"판단 Agent가 연차 규정을 확인하고, 일정 Agent가 이번 주 빈 날짜를 찾아서, 해당 날짜에 휴가를 자동 등록합니다."** |
| 4 | 통합 결과 확인 | **"실무에서 흔한 복합 요청을 한 번에 처리합니다. v7_planner LoRA가 87% 정확도로 인텐트를 분해합니다."** |

**촬영 팁**: Planner 분해 과정(AgentIndicator 변화) 잡기. depends_on으로 순차 실행되는 것이 핵심

## 씬 8. 관리자 + 마이페이지 + 쪽지/팝업 (20초)

> **멘트**: "관리자 페이지에서 규정을 관리하고 시스템 통계를 확인할 수 있습니다. 마이페이지에서는 개인 사용 통계를 볼 수 있고, 다크모드도 지원합니다. 그리고 어느 페이지에서든 우측 하단 버튼으로 쪽지와 AI 채팅에 바로 접근할 수 있습니다."

| 순서 | 동작 | 멘트 (자막) |
|:---:|------|--------|
| 1 | **관리자 페이지** | **"규정 업로드, 사용자 관리, 시스템 통계를 확인합니다."** |
| 2 | **마이페이지** | **"개인 사용 통계와 Google 연동 상태를 확인합니다."** |
| 3 | 다크모드 전환 | **"다크모드를 지원합니다."** |
| 4 | 우측 하단 **쪽지 버튼** 클릭 | **"어느 페이지에서든 팝업으로 팀원에게 쪽지를 보낼 수 있습니다."** |
| 5 | **AI 채팅 버튼** 클릭 | **"페이지 이동 없이 바로 AI에게 질문할 수도 있습니다. 전체 화면으로 확대도 가능합니다."** |

**촬영 팁**: 빠르게 훑기. 쪽지/AI 팝업은 어느 페이지에서든 접근 가능한 점 강조

> **엔딩 멘트**: "DUDE — 하나의 채팅으로 업무의 모든 것을. 감사합니다."

## 촬영 순서 & 편집 가이드

### 권장 촬영 순서

```
1차 (채팅 세션 A): 씬2 규정 판단 → 씬4 문서 QA/요약 → 씬5 문서 생성 → 씬6 일정 등록
2차 (채팅 세션 B): 씬7 복합 질문
3차 (페이지 탐색):  씬1 로그인/대시보드 → 씬3 문서 관리 → 씬6 서브페이지(4탭) → 씬8 관리자/마이페이지/쪽지/팝업
```

### 시간 배분 (편집 후 목표)

| 씬 | 내용 | 목표 시간 |
|:---:|------|:---:|
| 1 | 로그인 + 대시보드 | 25초 |
| 2 | 규정 판단 (4가지 유형) | 60초 |
| 3 | 문서 관리 | 30초 |
| 4 | 문서 QA + 요약 | 35초 |
| 5 | 문서 자동 생성 | 45초 |
| 6 | 일정 + 캘린더 + 서브페이지 | 45초 |
| 7 | 복합 질문 | 30초 |
| 8 | 관리자 + 마이페이지 + 쪽지/팝업 | 20초 |
| — | **합계** | **~4분 50초** |

### 편집 규칙

- SSE 스트리밍 대기: 시작 1초 → 점프컷 → 완성 결과
- 페이지 전환: 클릭 → 로딩 완료 직후 컷
- 타이핑: 실제 타이핑 or 붙여넣기 (자연스러운 쪽 선택)
- 각 씬 전환 시 짧은 페이드 or 하드컷
- 멘트는 **자막 or 나레이션** 중 선택 (자막 권장 — 편집이 쉬움)

### 촬영 전 준비 체크리스트

- [ ] 테스트 계정 데이터 세팅 (일정 5개+, 문서 10개+, 태스크 8개+, 결재 3개+)
- [ ] Google Calendar/Sheets 연동 완료
- [ ] 대시보드 위젯 보기 좋게 배치
- [ ] 브라우저 북마크/탭 정리 (불필요한 것 제거)
- [ ] 해상도: 1920x1080, 브라우저 줌 100%
- [ ] 알림/팝업 끄기
- [ ] 파이프라인에 프로젝트 1개 + 태스크 분산 배치 (4개 스테이지에 골고루)
- [ ] 결재 수신 목록에 pending 1~2건 미리 생성
- [ ] 쪽지 수신함에 읽지 않은 쪽지 1~2건 미리 생성
