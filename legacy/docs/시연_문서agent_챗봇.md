# 챗봇 시연 가이드

## 시나리오 1: 인사 + 사용법

### 순서
1. 채팅 입력: `안녕하세요`
2. 듀듀 응답 확인
3. **"사용법"** 버튼 클릭
4. 듀듀 소개 + 기능 안내 화면 캡처

### 시연 포인트
- 자연스러운 인사 응답
- 사용법 버튼으로 전체 기능 소개

---

## 시나리오 2: 챗봇 문서 생성 (회의록)

### 순서
1. 채팅 입력: `회의록 생성해줘`
2. 듀듀가 내용 입력 요청 → 아래 내용 입력:
```
3월 28일 CS팀 주간 정기회의 진행. 참석자 김민수 팀장, 박지연 대리, 이준호 사원, 최수정 인턴. 고객 불만 접수 시스템 개선 논의. 현재 평균 응답시간 48시간에서 24시간 이내로 단축 목표 설정. AI 챗봇 도입 결정. 1차 배포 4월 15일 확정. 김민수가 4월 5일까지 AI 벤더 비교 보고서 작성. 박지연이 4월 10일까지 고객 FAQ 데이터 정리. 이준호가 4월 12일까지 챗봇 시나리오 설계. 최수정이 4월 8일까지 경쟁사 CS 벤치마크 조사. 월간 고객 만족도 조사 4월부터 시작 결정.
```
3. 회의록 생성 완료 → **DOCX 다운로드** 클릭 → 문서 내용 확인
4. **"선택한 일정 등록"** 클릭 → 액션아이템이 캘린더/Pipeline에 등록되는 것 확인

### 시연 포인트
- 챗봇 대화로 문서 생성 (문서생성 페이지 안 가도 됨)
- 결정사항 3건 + 액션아이템 4건 자동 추출
- DOCX 다운로드 → 실제 문서 품질 확인
- 액션아이템 → 일정 등록 연동 (워크플로우 자동화)

---

## 시나리오 3: 문서 검색

### 순서
1. 채팅 입력: `보안 관련 문서 검색해줘`
2. 검색 결과 카드 확인 (5건, 관련도 점수 표시)

### 시연 포인트
- BM25 + Vector 하이브리드 검색 + Cross-Encoder Reranker 적용
- 관련도 점수로 검색 품질 시각화
- LLM 호출 없이 빠른 검색 결과 반환

---

## 시나리오 4: 문서 QA (질의응답)

### 순서 (새 세션에서 진행)
1. 채팅 입력: `클라우드 관련 계약 내용 자세히 알려줘`
2. QA 답변 확인 (참고 문서 5건 표시, 관련도 차등 점수)
3. follow-up 질문: `위 문서에서 계약 기간은 언제부터 언제까지야?`
4. 이전 문서 맥락을 유지한 답변 확인

### 시연 포인트
- RAG 검색 → LLM이 여러 문서를 종합하여 답변 생성
- 참고 문서 5건 + 관련도 점수 표시 (검색 투명성)
- follow-up 질문 시 이전 문서 맥락 유지 (멀티턴 대화)
- sLLM(Kanana-1.5-8B) 또는 GPT 모델 자동 선택

---

## 시나리오 5: 문서 요약

### 순서
1. 채팅 입력: `문서 요약해줘`
2. 문서 목록에서 **"클라우드_인프라_운영위탁_MSP"** 선택
3. 요약된 내용 확인

### 시연 포인트
- 업로드된 사내 문서를 AI가 자동 요약
- 긴 문서를 핵심만 추출해서 보여줌
