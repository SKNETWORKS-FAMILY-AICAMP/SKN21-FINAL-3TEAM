# Document Agent - System Architecture

## 전체 구조 Overview

```
                         +========================+
                         |    Document Agent       |
                         |    (4 Intents)          |
                         +========================+
                                    |
              +----------+----------+----------+----------+
              |          |          |          |          |
         doc_generate  doc_summary  doc_search   doc_qa
              |          |          |          |
              v          v          v          v
        [DOCX 생성]  [요약/저장]  [문서검색]  [질의응답]
```

---

## 1. 문서생성 (doc_generate)

### 1-A. 챗봇 경로

```
+----------+     +-----------+     +------------------+     +--------+     +----------+     +----------+
|  사용자   | --> |   Chat    | --> |     Intent       | --> |   DB   | --> |  Prompt  | --> |  sLLM    |
| (챗봇)   |     |  Interface |     |  Orchestrator    |     | (문서  |     |  Builder |     |  (JSON)  |
+----------+     +-----------+     +------------------+     | 파싱)  |     +----------+     +----------+
                                                            +--------+                          |
                                                                                                v
                                                                                         +----------+
                                                                                         |   DOCX   |
                                                                                         |   생성   |
                                                                                         +----------+
```

```
Flow: 사용자 채팅 --> Intent 분류 --> DB에서 문서 파싱 --> Prompt 구성 --> sLLM JSON 생성 --> DOCX 변환
```

### 1-B. 프론트엔드 페이지 경로

```
+-------------------+     +--------+     +-----------+     +----------+     +----------+     +----------+
|  템플릿 선택       | --> |   DB   | --> |  사용자    | --> |  Prompt  | --> |  sLLM    | --> |   DOCX   |
|                   |     |        |     |  입력폼    |     |  Builder |     |  (JSON)  |     |   생성   |
| +---------------+ |     +--------+     +-----------+     +----------+     +----------+     +----------+
| | 기본 템플릿    | |
| +---------------+ |
| | 커스텀 템플릿  | |
| +---------------+ |
+-------------------+
```

```
Flow: 템플릿 선택(기본/커스텀) --> DB 조회 --> 사용자 입력 --> Prompt 구성 --> sLLM JSON 생성 --> DOCX 변환
```

## 2. 문서요약 (doc_summary)

### 2-A. 문서 업로드 & 요약 저장

```
+----------+     +------------+     +------------+     +----------+     +--------+
|  사용자   | --> |  문서 업로드 | --> |  문서 파싱  | --> |  sLLM    | --> |   DB   |
|          |     | (PDF/DOCX/ |     | (Docling/  |     | (요약    |     | (요약  |
|          |     |  HWP/TXT)  |     |  PaddleOCR)|     |  생성)   |     |  저장) |
+----------+     +------------+     +------------+     +----------+     +--------+
```

```
Flow: 사용자 문서 업로드 --> 문서 파싱(Docling/PaddleOCR) --> sLLM 요약 생성 --> DB 저장
```

### 2-B. 챗봇에서 요약 조회

```
+----------+     +------------+     +--------+     +----------+
|  사용자   | --> |  문서 선택  | --> |   DB   | --> |  요약    |
| (챗봇)   |     |            |     | (저장된 |     |  출력    |
+----------+     +------------+     |  요약)  |     +----------+
                                    +--------+
```

```
Flow: 사용자 문서 선택 --> DB에서 저장된 요약 조회 --> 요약 내용 출력
```

### 2-C. 문서관리 페이지

```
+------------------+     +--------+     +----------+
|  문서관리 페이지   | --> |   DB   | --> |  요약    |
|  (Front)         |     | (저장된 |     |  표시    |
|                  |     |  요약)  |     |          |
| +- 문서 목록 --+ |     +--------+     +----------+
| | doc1.pdf     | |
| | doc2.docx    | |        * 챗봇과 동일한 요약 기능 사용
| | doc3.hwp     | |
| +--------------+ |
+------------------+
```

## 3. 문서검색 (doc_search)

```
+----------+     +-------------+     +------------------+     +--------------------+
|  사용자   | --> |  질문 입력   | --> |    RAG Pipeline   | --> |  검색 결과 출력     |
|          |     |             |     |                  |     |                    |
+----------+     +-------------+     | +- Qdrant -----+ |     | +- 관련문서 목록 -+ |
                                     | | Vector Search | |     | | [doc1] 90%     | |
                                     | +- BM25 ------+ |     | | [doc2] 85%     | |
                                     | | Keyword      | |     | | [doc3] 78%     | |
                                     | +- Reranker --+ |     | +----------------+ |
                                     | | bge-reranker | |     | +- 미리보기 -----+ |
                                     | +--------------+ |     | | 문서 내용 일부  | |
                                     +------------------+     | +----------------+ |
                                                              +--------------------+
```

```
Flow: 사용자 질문 --> Qdrant(Vector) + BM25(Keyword) --> Reranker 정렬 --> 관련문서 목록 + 미리보기
```

## 4. 문서QA (doc_qa)

```
+----------+     +-------------+     +------------------+     +------------------+     +----------+     +----------+
|  사용자   | --> |  질문 입력   | --> |   RAG Pipeline   | --> |  Prompt Builder  | --> |  sLLM    | --> |  답변    |
|          |     |             |     |                  |     |                  |     |          |     |  생성    |
+----------+     +-------------+     | +- Qdrant -----+ |     | +- 문서내용 ---+ |     +----------+     +----------+
                                     | | Vector Search | |     | | (RAG 결과)  | |
                                     | +- BM25 ------+ |     | +- 질문 ------+ |
                                     | | Keyword      | |     | | (사용자)    | |
                                     | +- Reranker --+ |     | +--------------+ |
                                     | | bge-reranker | |     +------------------+
                                     | +--------------+ |
                                     +------------------+
```

```
Flow: 사용자 질문 --> RAG(Qdrant + BM25 + Reranker) --> 문서내용 + 질문 조합 --> Prompt --> sLLM --> 답변 생성
```

## 기술 스택

| 컴포넌트 | 기술 |
|---------|------|
| sLLM | Kanana 1.5 8B + QLoRA (vLLM 서빙) |
| 문서파싱 | Docling, PaddleOCR, python-docx |
| RAG | Qdrant (Vector) + BM25 (Keyword) + bge-reranker |
| 문서생성 | python-docx (DOCX 변환) |
| DB | PostgreSQL (SQLAlchemy) |
| 프론트엔드 | React + Vite + Tailwind + shadcn/ui |
| 백엔드 | FastAPI + SSE |
