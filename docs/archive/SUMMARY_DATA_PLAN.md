## 기존 합성 700건 현황 (1차 생성 완료)

- 전부 3K 이하 (max_tokens 설정 오류 — GPT-4o 한국어 1자≈1.5~2토큰인데 0.6으로 계산)

3. 나머지 기존 데이터 버림

## 새로 생성할 400건

### 중간+ (3K~5K): 150건
- 카테고리: 보고서, 간행물, 계약서/법률문서, 사설/연설문 등
- 방법: 멀티턴 이어쓰기 (GPT-4o 1회 호출 한국어 ~2,500자 한계)

### 긴 (5K~10K): 250건
- 카테고리: 보고서, 계약서/법률문서, 간행물, 회의록 등
- 방법: 멀티턴 이어쓰기 (max 5라운드)

### 멀티턴 이어쓰기 방식
```
1라운드: 문서 생성 요청 → ~2,500자
2라운드: "아직 N자입니다. M자 이상 필요합니다. 이어서 계속 작성하세요." → 추가
3라운드~: 목표 달성까지 반복 (최대 5라운드)
```

### max_tokens 설정 (수정 후)
```
목표 ~3K  → max_tokens = 4096
목표 3K~5K → max_tokens = 8192
목표 5K~8K → max_tokens = 12000
목표 8K+  → max_tokens = 16384
```
