# DUDE 데모 시나리오

> **4분 30초 시연** | 8개 씬 | 3개 Agent + Planner 전체 기능 커버

---

## 전체 흐름 요약

```
로그인 → 대시보드 → 규정 판단 → 문서 관리 → 문서 QA/요약 → 문서 생성 → 일정/캘린더 → 복합 질문 → 관리자
```

각 씬은 **"무엇을 보여주는가"** + **"왜 의미 있는가"**로 구성했습니다.

---

## 씬 1. 로그인 + 대시보드 _(25초)_

**보여주는 것**: 서비스 첫인상, 한눈에 보는 업무 현황

| 동작 | 화면 |
|------|------|
| 로그인 | ID/PW 입력 → 메인 화면 진입 |
| 대시보드 위젯 훑기 | 오늘 일정 타임라인, 최근 문서, 태스크 파이프라인, AI 채팅, 승인 대기열 |
| 위젯 드래그 드롭 | 편집 모드에서 위젯 위치 변경 (커스터마이즈) |

> **의미**: 여러 앱에 흩어진 업무 정보를 하나의 대시보드에서 한눈에 확인

## 씬 2. 규정 판단 — Judgment Agent _(60초)_

**보여주는 것**: 사내 규정 기반 AI 판단 + 환각 방지 구조

| 동작 | 화면 |
|------|------|
| 새 대화 생성 | 채팅 페이지 이동 |
| 질문 1 — **conditional** | `"인턴에게 AWS 콘솔 접근 권한을 줘도 되나요?"` |
| 응답 확인 | JudgmentCard: **conditional** 뱃지, 조건: "보안교육 이수 + 부서장 승인", 근거: 정보보안규정 제25조 |
| 질문 2 — **yes** | `"재택근무 시 VPN 접속이 필수인가요?"` |
| 응답 확인 | **yes** 뱃지, 근거: 정보보안규정 관련 조항 |
| 질문 3 — **no** | `"공용 Wi-Fi에서 업무 시스템에 접속해도 되나요?"` |
| 응답 확인 | **no** 뱃지, 근거: 제9조 원격근무 — 공용 Wi-Fi 사용 금지 명시 |
| 질문 4 — **no_regulation** | `"점심시간에 회사 근처 헬스장 다녀도 되나요?"` |
| 응답 확인 | **no_regulation** 뱃지, "해당 사항을 다루는 규정이 없습니다" |

> **의미**: 4가지 판단 유형(yes/no/conditional/no_regulation)을 모두 시연. LLM이 판단만 하는 게 아니라 **4중 보조장치**로 환각을 검증하고, **실존하는 규정 조항만** 인용. 규정이 없으면 없다고 솔직하게 답변 (no_regulation 인식률 6%→97%)

## 씬 3. 문서 관리 _(30초)_

**보여주는 것**: 문서 업로드 → AI 자동 분류 → 검색

| 동작 | 화면 |
|------|------|
| 문서 페이지 이동 | 문서 목록 (회사/팀 스코프 필터) |
| PDF 드래그앤드롭 업로드 | 파일 업로드 |
| AI 자동 분류 확인 | 카테고리, 태그, 요약이 **자동**으로 채워짐 |
| 키워드 검색 | 결과 하이라이트 |
| 문서 클릭 → 상세 페이지 | 미리보기 + AI 요약 + 메타데이터 |

> **의미**: 문서를 올리기만 하면 AI가 분류/태그/요약까지 자동 처리. 검색 시 BM25+Vector 하이브리드 + Reranker로 정확도 극대화

## 씬 4. 문서 QA + 요약 — Document Agent _(35초)_

**보여주는 것**: 업로드된 문서에 대한 질의응답 + 자동 요약

| 동작 | 화면 |
|------|------|
| 채팅에서 QA 질문 | `"클라우드 관련 계약 내용 자세히 알려줘"` |
| DocumentCard 확인 | 답변 + **참고 문서 5건** (관련도 점수 표시) |
| follow-up 질문 | `"위 문서에서 계약 기간은 언제부터 언제까지야?"` |
| 맥락 유지 답변 | 이전 문서 컨텍스트 유지한 답변 |
| 요약 요청 | `"문서 요약해줘"` → 문서 선택 → 분류/태그/요약 결과 |

> **의미**: RAG로 여러 문서를 종합 답변 + 출처 투명하게 표시. search는 **LLM 호출 없이** 최고속, QA는 sLLM이 문서 기반 답변 생성

---

## 씬 5. 문서 자동 생성 — Document Agent _(45초)_

**보여주는 것**: 자연어 → 구조화 문서 자동 생성 (두 가지 경로)

### 경로 A: 채팅에서 생성

| 동작 | 화면 |
|------|------|
| 생성 요청 | `"회의록 생성해줘"` → 듀듀가 내용 요청 |
| 내용 입력 | `"3월 28일 CS팀 주간 정기회의. 참석자 김민수 팀장, 박지연 대리..."` |
| GenerateCard 확인 | 제목, 결정사항 3건, 액션아이템 4건 자동 추출 |
| DOCX 다운로드 | 파일 열어서 결과 확인 |
| 일정 등록 제안 | `"선택한 일정 등록"` 클릭 → 액션아이템이 캘린더에 자동 등록 |

### 경로 B: 문서 생성 전용 페이지

| 동작 | 화면 |
|------|------|
| 전용 페이지 이동 | 템플릿 선택 (회의록 / 보고서 / 제안서 / **커스텀**) |
| 폼 입력 | 제목, 날짜, 팀, 내용 입력 |
| AI 문서 작성 | 필드 자동 채움 확인 |
| DOCX 생성 및 다운로드 | 완성된 문서 확인 |

> **의미**: v3_generate LoRA로 **content 채움률 34%→100%**, False Fill 44.3%→17.9%. 없는 정보를 지어내지 않고, 입력에서 결정사항/액션아이템을 정확 추출. 커스텀 템플릿은 회사 자체 Word 양식을 그대로 사용 가능

## 씬 6. 일정 + 캘린더 + 서브페이지 — Schedule Agent _(45초)_

**보여주는 것**: 자연어 일정 등록 + Google Workspace 5종 연동 + 파이프라인/결재/Sheets

| 동작 | 화면 |
|------|------|
| 일정 요청 | `"내일 오후 3시에 팀 회의 잡아줘"` |
| ScheduleCard | 날짜/시간 파싱 → Google Calendar 동기화 완료 |
| 후속 제안 | "Meet 링크 생성할까요?" → `"응"` → Meet 링크 자동 생성 |

**일정 페이지 4개 탭 순회:**

| 탭 | 보여주는 것 |
|:---:|------|
| **calendar** | FullCalendar에서 방금 등록한 일정 확인, Google Calendar 양방향 동기화 |
| **pipeline** | 칸반 보드 (To Do → In Progress → Review → Done), 프로젝트 폴더뷰, 태스크 드래그 드롭 |
| **approvals** | 결재 대기열, 승인/거절 |
| **sheets** | Google Sheets 내보내기 → WBS/Gantt 차트 자동 생성 |

> **의미**: 하나의 채팅에서 일정 등록 → Meet 생성 → 초대 메일까지 자동 처리. 파이프라인/결재/Sheets는 일정 페이지에서 **탭 하나로 통합 관리**

## 씬 7. 복합 질문 — Planner Agent _(30초)_

**보여주는 것**: 여러 인텐트를 한 문장에 → 자동 분해 → 병렬 처리

| 동작 | 화면 |
|------|------|
| 복합 질문 입력 | `"연차 규정 확인하고 이번주 일정 보고 비는 날에 휴가 등록해줘"` |
| Planner 분해 | step1: judgment (연차 규정), step2: schedule_view (이번주 일정), step3: schedule_add (비는 날 휴가) |
| 결과 도착 | JudgmentCard → 일정 목록 → ScheduleCard 순차 도착 |
| 통합 결과 | 규정 확인 → 빈 날짜 파악 → 해당 날짜에 휴가 등록까지 자동 연결 |

> **의미**: 3개 인텐트가 **의존성**을 가진 실제 업무 시나리오. 규정 확인 → 일정 조회 → 등록이 순차적으로 연결되며, v7_planner LoRA가 depends_on으로 순서를 자동 결정

## 씬 8. 관리자 + 마이페이지 _(15초)_

| 동작 | 화면 |
|------|------|
| 관리자 페이지 | 규정 관리 (목록/업로드), 시스템 통계, 사용자 관리 |
| 마이페이지 | 프로필, 사용 통계 (채팅/문서/일정), Google 연동 상태 |
| 다크모드 전환 | 테마 변경 |
| 우측 하단 쪽지 버튼 클릭 | MessagePopup: 받은/보낸 쪽지, 쪽지 작성 → 전송 |
| AI 채팅 버튼 클릭 | AIChatPopup: 추천 질문 + 최근 대화, 팝업에서 바로 질의 → 전체 화면 확대 |

> 빠르게 훑기. 쪽지/AI 팝업은 **어느 페이지에서든** 페이지 이동 없이 접근 가능 — 업무 흐름을 끊지 않는 UX

## 기술 하이라이트 (멘토님 참고용)

시연 중 언급하면 좋을 핵심 기술 포인트:

| 포인트 | 씬 | 설명 |
|--------|:---:|------|
| **sLLM 온프레미스** | 전체 | GPT API 과금 0원, 데이터 외부 전송 없음, LoRA 핫스왑 ~100ms |
| **4중 보조장치** | 씬2 | LLM 환각 방지: 키워드 매칭 + 조항 검증 + 카테고리 제한 + 일관성 모니터링 |
| **5-factor Confidence** | 씬2 | LLM×0.6 + RAG×0.25 + coverage×0.15 - penalties, Hard Cap으로 과신 방지 |
| **RAG 하이브리드** | 씬3,4 | BM25 + Vector + RRF + Reranker → MRR 0.636→0.952, Context Recall 0.944 |
| **LoRA 파인튜닝 4종** | 씬2,5,7 | 판단 37.2%→85.4%, 문서생성 False Fill 44.3%→17.9%, Planner 71%→87% |
| **2차 분류** | 씬6 | schedule_add 내에서 일정/태스크/결재를 키워드 기반 자동 분기 |
| **Google 5종 양방향** | 씬6 | Calendar, Meet, Gmail, Tasks, Sheets — 양방향 동기화 |
| **AI 추천** | 씬6 | sLLM → OpenAI → 규칙 기반 3단계 fallback으로 결재/일정 자동 추천 |
