# 08-1. 판단 Agent 상세 (1페이지)

> 슬라이드 제목: **판단 Agent 상세** | 부제: 3중 보조장치 + 5-factor 신뢰도 보정

---

### 처리 흐름 (좌측 배치)

```
1. RAG 검색 (규정 Top-5, Reranker+HyDE)
2. 규정 그룹핑 (chapter별 묶기)
3. 이전 판단 이력 참조
4. sLLM 판단 (v1_judgment LoRA)
5. 3중 보조장치 검증
6. Confidence 보정 → SSE 스트리밍
```

### 3중 보조장치 (우측 상단)

| 보조장치 | 역할 |
|--------|------|
| 규정 키워드 매칭 | LLM 인용 조항이 RAG에 실존하는지 (매칭률 0~1.0) |
| 조항 존재 검증 | 제N조가 실제 있는지, 없으면 환각 플래그 |
| 판단 카테고리 제한 | yes/no/conditional/no_regulation 외 차단 |

### 5-factor Confidence 보정 (우측 하단)

```
(LLM raw x 0.60) + (RAG avg x 0.25) + (커버리지 x 0.15)
 - 충돌 감점 - 환각 감점 - 미존재 감점
```

Hard Cap: RAG < 0.2 → max 0.4 | 전부 미존재 → max 0.25

### 핵심 메시지 (하단 바)

> LLM 판단을 맹신하지 않음 → RAG 근거 기반 다중 검증 + 신뢰도 자동 보정 → 환각 방지
