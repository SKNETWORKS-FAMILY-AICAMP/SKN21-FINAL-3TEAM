# 문서 Agent LoRA v2 — 학습 데이터 예시

> 모든 학습 데이터는 ChatML 형식 (`{"messages": [system, user, assistant]}`)으로 저장됨.
> 아래 예시에서 system 프롬프트는 지면상 생략하고, user/assistant 부분만 표시합니다.

---

## 1. AIHub 원본 데이터 (변환 전)

학습 데이터의 원천이 되는 AI Hub 원본 데이터 구조입니다.

### 1-1. AI Hub 022 — 요약문 및 레포트 생성 데이터 (SN 582)

> v2_summary, v2_generate, v2_qa(일부)의 원천 데이터.
> 각 JSON 파일에 `passage`(원문) + `summary`(요약)이 포함.

**파일**: `REPORT-minute-00001-00004.json` (회의록 카테고리)

```json
{
  "Meta(Acqusition)": {
    "doc_id": "REPORT-minute-00001",
    "doc_category": "REPORT",
    "doc_type": "minute",
    "doc_name": "제19대 국회 교육과학기술위원회 회의록 데이터셋_16481.csv",
    "author": null,
    "publisher": null,
    "doc_origin": "국회도서관 포털"
  },
  "Meta(Refine)": {
    "passage_id": "REPORT-minute-00001-00004",
    "passage": "위원장 신학용] \"수고하셨습니다. 다음은 존경하는 현영희 위원님 인사말씀해 주세요.\"\n현영희 위원] \"저는 부산 출신이고 비례대표 현영희입니다. 우리 교육이 잘 돼야 나라가 잘됩니다 ...\"\n김태년 위원] \"반갑습니다. 경기도 성남 수정구 출신 김태년입니다. 4년 만에 상임위원회 회의실에 들어와 봅니다 ...\"\n박혜자 위원] \"안녕하세요. 저는 광주 서갑의 박혜자입니다. 교과위가 무엇보다도 우리 아이들의 미래를 열어가는 장을 만들어 낼 수 있다라는 점에서 ...\"",
    "passage_Cnt": 873
  },
  "Annotation": {
    "summary1": "아이들의 미래를 열어가는 장을 만들 수 있는 교과위에 오기를 기대했던 박 위원은 아이들을 위한 일에 힘을 보태고 싶다고 말했다.",
    "summary2": null,
    "summary3": "박혜자 위원] \"안녕하세요. 저는 광주 서갑의 박혜자입니다. 그러나 교과위가 무엇보다도 우리 아이들의 미래를 열어가는 장을 만들어 낼 수 있다라는 점에서 ..."
  }
}
```

**활용 방식**: `passage`(원문)를 GPT-4o에게 보내서 → 요약/QA쌍/구조화 JSON을 생성시킴

### 1-2. AI Hub 016 — 행정 문서 대상 기계독해 데이터 (SN 569)

> v2_qa의 원천 데이터 (300건). 이미 question + answer가 있어 GPT 없이 직접 변환.

**파일**: `TL_span_extraction.json` (본문 답 추출 유형)

```json
{
  "doc_id": "D0000042870847",
  "doc_title": "노후 어린이집 누수 제로 추진 결과 보고",
  "doc_source": "서울특별시청",
  "doc_published": 20210626,
  "doc_class": {
    "class": "중앙행정기관 분류체계",
    "code": "공공행정"
  },
  "paragraphs": [
    {
      "context": "노후 어린이집 누수 제로 추진 결과 보고\nⅠ 추진 근거\n「영유아보육법 시행령」제12조\n「서울특별시 강남구 영유아 보육 및 지원에 관한 조례」제15조, 제27조\n2021년도 구립어린이집 확충 및 시설관리 계획(2021.1.12.보육지원과-729호)\nⅡ 추진 개요\n사 업 명 : 노후 어린이집 누수 긴급 개보수 공사\n사업기간 : 2021. 4. 7. ~ 6. 25.\n총사업비 : 금55,570,000원\n사업대상 : 신사어린이집 외 3개소",
      "qas": [
        {
          "qa_type": 1,
          "question": "노후 어린이집 누수 개보수에 책정된 경비가 얼마야",
          "is_impossible": false,
          "answers": {
            "text": "금55,570,000원",
            "answer_start": 210
          }
        },
        {
          "qa_type": 1,
          "question": "얼마의 비용으로 노후 어린이집 누수 문제를 해결하니",
          "is_impossible": false,
          "answers": {
            "text": "금55,570,000원",
            "answer_start": 210
          }
        }
      ]
    }
  ]
}
```

**활용 방식**: `context` -> user의 Context, `question` -> Question, `answers.text` -> assistant의 answer로 직접 변환 (GPT 불필요)

## 2. v2_generate — 문서 생성 (3개 예시)

> 사용자가 회의 내용/업무 내용을 입력하면, 필드 명세에 맞춰 구조화된 JSON을 생성하는 학습 데이터

### 예시 1: 회의록 (AIHub 변환 — 국회 회의록 원문 기반)

**[user]**
```
다음 내용을 바탕으로 문서를 JSON 형식으로 작성해주세요.

[문서 유형] 회의록

[필드 명세]
- title: 회의 주제를 반영한 구체적인 제목
- date: 회의 날짜 (YYYY-MM-DD 형식)
- attendees: 참석자 이름 배열
- summary: 회의에서 논의된 주요 내용을 3~5문장으로 요약
- decisions: 결정된 사항 목록 (배열)
- action_items: 후속 조치 목록 배열
- agenda: 회의 안건 목록 (배열)
- location: 회의 장소

[회의 내용]
식품의약품안전처장 정승] "예 그렇게 하겠습니다. 규제 완화 기조를 강조하면서 군별
단계적 완화 방안을 검토해 보겠습니다."
문정림 위원] "중고의료기기 검사필증제의 문제점을 지적합니다. 검사기관이 하나뿐이라

## 3. v2_qa — 문서 QA (3개 예시)

> RAG로 검색된 문서 청크(Context)와 사용자 질문(Question)을 입력받아, 답변 + 근거 인용을 JSON으로 반환하는 학습 데이터

### 예시 1: AIHub MRC 직접 변환 (SN 569, GPT 미사용)

**[user]**
```
Context:
["기술력 우수한 창업기업, 벤처기업 인증 쉬워진다 - 기술성 중심으로 벤처기업
확인제도 개선 -\n벤처투자 유형\n□ 투자 유형 벤처기업으로 확인받기 위해서는
창업투자회사 등 벤처 투자기관으로부터 5천만원 이상 투자를 받아야 한다.
앞으로는 벤처경험을 통해 우수기업을 선별하는 능력을 갖춘 전문 엔젤투자자도
벤처투자기관에 포함하고, 해외 벤처캐피탈(VC)로부터 사업성을 인정받아 투자를
유치한 기업도 벤처확인 기회를 부여하기로 하였다."]

Question: 벤처기업 확인제도가 어떻게 개선되었나요?

### 데이터 구성 특징

- **ChatML 형식**: 모든 데이터가 `{"messages": [system, user, assistant]}` 통일 형식
- **동적 필드 (generate)**: 19~20개 필드 풀에서 매번 6~10개를 랜덤 조합 → 어떤 필드 조합에도 대응 가능
- **not-found 학습 (qa)**: 12%의 "답 없음" 응답 포함 → hallucination 방지
- **GPT-4o 라벨러**: AI Hub 원본에 없는 형식(구조화 JSON, QA쌍, 마크다운 요약)을 GPT-4o가 생성
- **JSONL 포맷**: 한 줄 = 1건 → 중간 중단에도 데이터 유실 없음
